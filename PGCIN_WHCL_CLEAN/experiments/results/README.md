# Manuscript-aligned derived results

These CSV and MAT files are derived outputs used by the manuscript tables, figure inputs, and validation checks. They are not raw image data and contain no secret keys or credentials.

The files are copied from the final canonical result set. Historical smoke runs, exploratory probes, intermediate logs, and machine-specific manifests are intentionally excluded. Re-running the suite writes fresh outputs under `experiments/runs/`.

The `figure_data/` subdirectory contains the saved data required to regenerate the automatic paper figures without rerunning encryption for every plot.
