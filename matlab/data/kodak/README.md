# Kodak-24 data directory

The original Kodak-24 PNG files are intentionally not redistributed in this
repository. Obtain them from the original source under its applicable terms,
place `kodim01.png` through `kodim24.png` in this directory, and verify them
against `kodak24_checksums.csv` before running the natural-image experiments.

The experiment scripts require the local files for Kodak-24 measurements. The
repository contains the derived result tables used by the manuscript, not the
third-party source images.
